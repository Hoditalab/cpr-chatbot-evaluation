# cpr-chatbot-evaluation
This repository contains the full evaluation, analysis, and improvement plan for a CPR emergency chatbot built using the RASA framework.

# project overview
This project evaluates how well a CPR chatbot:

understands CPR‑related questions

provides accurate and safe CPR guidance

maintains readability suitable for emergencies

handles intents, templates, and NLU classification

avoids irrelevant or incorrect medical advice
